# Audit register

The shipped code cites short identifiers (`D-0012`, `A-005`, `SS8`, `PAP-v4 §3.1`) in comments
and docstrings. Those identifiers originate in a larger internal research archive that is **not**
redistributed with this submission, which previously left them unresolvable for anyone reading
the package (audit finding F-9).

This file resolves every identifier that survives in the shipped code. Each entry states what the
identifier refers to and where the corresponding code lives, so a reader can check the claim
against the implementation rather than against an archive they cannot see.
